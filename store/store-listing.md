Browser Agent

Productivity (Üretkenlik)

## TÜRKÇE

### Kısa açıklama (en fazla 132 karakter)
Tarayıcında senin için işlem yapan yapay zeka. Doğal dille görev ver; arama yapar, form doldurur, veri toplar.

### Detaylı açıklama

Browser Agent, tarayıcınızda sizin adınıza görevleri yapan bir yapay zeka
asistanıdır. Bir görevi doğal dilde yazın — ajan sayfayı okur, karar verir ve
tıpkı bir insan gibi adım adım yapar.

**Neler yapabilir?**
• Web sitelerinde gezinir, arama yapar, sonuçları özetler
• Formları doldurur, butonlara tıklar
• Birden fazla siteden veri toplayıp karşılaştırır
• Sekmeler arası çalışır — bir sekmedeki bilgiyi diğerinde kullanır
• Yüklediğiniz dosya (CSV, JSON, TXT) üzerinden işlem yapar
• Geçmiş sohbetlerinizi saklar, kaldığınız yerden devam edersiniz

**Kendi yapay zeka sağlayıcınızı seçin**
Anthropic (Claude), OpenAI (GPT), Google Gemini, OpenRouter, DeepSeek, Groq veya
yerel Ollama — kendi API anahtarınızı girin, istediğiniz modeli kullanın.

**Gizlilik önce gelir**
Uzantının kendi sunucusu yoktur. API anahtarınız ve sohbet geçmişiniz yalnızca
sizin tarayıcınızda saklanır. Sayfa içeriği yalnızca seçtiğiniz yapay zeka
sağlayıcısına gönderilir — bize hiçbir veri gelmez.

**Güvenlik**
Ödeme, silme, gönderme gibi geri döndürülemez işlemlerden önce onayınızı ister.
Görevi istediğiniz an durdurabilirsiniz.

Not: Uzantı, seçtiğiniz yapay zeka sağlayıcısının API anahtarını gerektirir.

## ENGLISH

### Short description (max 132 characters)
An AI that acts in your browser. Give a task in plain language; it searches, fills forms, and gathers data for you.

### Detailed description

Browser Agent is an AI assistant that performs tasks in your browser on your
behalf. Write a task in plain language — the agent reads the page, decides, and
does it step by step, just like a human.

**What can it do?**
• Browse websites, search, and summarize results
• Fill in forms and click buttons
• Gather and compare data from multiple sites
• Work across tabs — use info from one tab in another
• Act on a file you upload (CSV, JSON, TXT)
• Save your chat history so you can pick up where you left off

**Bring your own AI provider**
Anthropic (Claude), OpenAI (GPT), Google Gemini, OpenRouter, DeepSeek, Groq, or
local Ollama — enter your own API key and use the model you like.

**Privacy first**
The extension has no server of its own. Your API key and chat history stay in
your browser only. Page content is sent solely to the AI provider you choose —
nothing comes to us.

**Safety**
It asks for your approval before irreversible actions like paying, deleting, or
sending. You can stop a task at any time.

Note: The extension requires an API key from the AI provider you choose.
